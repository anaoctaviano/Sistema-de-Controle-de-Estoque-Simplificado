# SISTEMA DE CONTROLE DE ESTOQUE SIMPLIFICADO

## Descrição do Projeto:

Esse projeto é um sistema que executa o controle de um estoque de maneira simplificada, para ajudar as pessoas a gerenciarem os produtos de um estoque.
O objetivo principal é adicionar, alterar e buscar um produto de maneira automatizada.

## Funcionalidades:

Ao iniciar o código temos o Menu Interativo com as seguintes opções:
1- Adicionar produto
2- Listar todos os produtos
3- Buscar produto por ID
4- Atualizar estoque
5- Remover produto
6- Sair do programa

Ao escolher a opção 1, você irá adicionar um novo produto no estoque e para isso é preciso preencher as seguintes informações:
- ID
- Nome do produto
- Quantidade do produto
- Localização do produto

Ao escolher a opção 2, o sistema listará todos os produtos existentes no estoque em uma lista mostrando na seguinte estrutura:
[ID, nome do produto, quantidade, localização]

Ao escolher a opção 3, você irá buscar um produto usando o ID dele. O sistema vai mostrar em que linha se encontra o produto e as informações sobre ele.

Ao escloher a opção 4, você irá atualizar a quantidade de um produto do estoque. Para isso é preciso informar o ID do produto que será alterado. 
Caso o produto existir no estoque, o sistema pedirá a nova quantidade desse produto.
Caso o sistema não encontre o produto desejado, o sistema irá informar que esse ID não foi encontrado.

Ao escolher a opção 5, você irá remover um item usando o ID dele.
Caso o produto existir no estoque, o sistema mostrará as informações sobre o produto e depois irá removê-lo.
Caso o sistema não encontre o produto, o sistema informará que o ID não foi encontrado.

Ao escolher a opção 6, você irá parar o sistema de estoque.
